# Homebrew tap

```sh
brew trust --cask hrvojecukman/tap/toranj   # Homebrew asks you to trust third-party casks once
brew install --cask hrvojecukman/tap/toranj
```

| Cask | |
| --- | --- |
| [toranj](https://github.com/hrvojecukman/toranj) | One window for all your coding agents (macOS, Apple silicon). Installs tmux too. |
